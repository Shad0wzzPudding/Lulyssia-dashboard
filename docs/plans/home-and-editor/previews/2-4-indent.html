Indent lines in a description

A working copy of the description box with the proposed rules. Try them below. Intent only: the real editor keeps its bold, italic, bullets and the rest; only these keys and the new button are new.

  • Tab indents the line the caret is on, or every selected line, by 6 spaces. Shift+Tab takes up to 6 spaces back off.
  • Space with whole lines selected (or a selection running over 2+ lines) adds 1 space at the start of each of those lines instead of replacing the text. Inside one line it types a space as usual.
  • ⇥ Tab button: the same as the Tab key (keeps the selection, so you can press it again).
  • To leave the box with the keyboard: Esc, then Tab moves on as usual.
