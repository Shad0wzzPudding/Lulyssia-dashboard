  • Only same-day items change. A task or event that only starts, or only ends, on that day keeps today's look ("Starting" / "Deadline" / "Starts:" / "Ends:").
  • A keeps a badge so a same-day item still stands out in the list, and the range chip keeps the green start and red end colours. B is quieter: no badge, one cyan range.
