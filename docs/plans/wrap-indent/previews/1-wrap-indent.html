Wrapped lines and indents

When a long line wraps, where should the wrapped part start? Same text in each box: "Test tab behavior" after pressing Tab on its first point. Drag the width to see more or less wrapping. Intent only: the build keeps the editor's own look; only where wrapped rows start changes. The thin cyan guide marks where each line's wrapped rows begin.

Now
Wrapped rows always start at the left edge, even under an indented line.
A · Under the indent
Wrapped rows start where the line's first character is (after its spaces). Lines with no spaces stay as now.
B · Under the text after the bullet (recommended, like Word)
As A, and for a line starting with a bullet ("- ", "• ", "1. "), wrapped rows start under the text, so the bullet stands out on its own. Works with no Tab too.
  • Only how it looks changes. The text saved stays exactly the same (spaces and line breaks); nothing is added to it.
  • It would apply in the description editor and everywhere a description is shown: Tasks, Events and Interests cards, and Home (Today lists, calendar, details window).
  • LINE can't do this: LINE wraps the message itself, so a wrapped row there still starts at the left.
