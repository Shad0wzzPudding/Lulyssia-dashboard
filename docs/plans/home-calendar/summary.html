An event's start line is green

In the date panel, the thin line at an item's left edge is green when it starts that day, for events too, matching its green start time. Ends stay red, and an item that starts and ends that day keeps its green-and-red line.

Only the round circle marks a date

A date with a task or event shows just the round circle behind its number; the square block behind it goes. Hiding a date's mark goes too (with the eye button), so any date hidden before shows its circle again.

A plus makes a task or event on that date

The eye button becomes a plus. It opens a small menu, "New task" or "New event", and the form opens with the picked date filled in: a task's Deadline, an event's Start. The time is the next full hour on today, 09:00 on other dates. Everything else starts empty and saves as usual.

After the build

  1. Build: in a cloud session, run the command below. Each item gets its own branch (item 3 builds on item 2), plus a summary branch with the order to merge them.
  2. Check and merge: come back to Claude, which checks each branch with you and merges them in order.
  3. Deploy: nothing to deploy and no migration; it all goes out with the next Vercel deploy.
  4. Look and try: the green line beside an event's start, the circles next to today's ring, and the plus with its menu on a computer and a phone (plus the sound when the form opens).
