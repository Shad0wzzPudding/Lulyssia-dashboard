Tasks page

1

A Today's Tasks section with tabs

Every unfinished task that starts or is due today moves into a new Today's Tasks section, after the Daily tasks. Tabs: All, Start today, End today. In Progress keeps what started on an earlier day and ends later. A task already past its deadline stays in Overdue.

Where: Tasks page, sections and the count tiles (a Today tile first)

Events page

1

Today's Events also holds what ends today, with tabs

Today's Events lists events that start or end today (an event that ends today leaves In Progress), with the same three tabs. Nothing today: the section stays with its "No events scheduled for today" card, and Today's Tasks gets a matching "No tasks for today".

Descriptions: the form, every card, Home

2

Checklists, with a progress bar above the name

A ☑ Check button (after ⇥ Tab) turns lines into checklist lines; Enter on one starts the next. Tick the boxes in the description box or straight on the card. Above the name, a thin bar shows "N / M done", green when all are ticked; ticking a task's last box offers to mark it done.

Where: task, event and interest forms; their cards; Home's Today lists, Main Focus, details window; Home's In progress cards (bar only)
