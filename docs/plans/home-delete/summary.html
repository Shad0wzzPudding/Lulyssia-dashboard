Home delete build

What changes on Home's Calendar Overview once the plan home-delete is built and merged: the plus becomes + / −, the minus turns on a delete mode with a red delete button on each item, and deleting from there asks first, with "Don't ask again today". The Tasks and Events pages' deletes don't change. Decided together on 4 Nov 2026; the cloud build follows docs/plans/home-delete/plan.md.

Items 1–2, both on Home's date panel
1

"+ / −" and a delete mode that asks first

Next to the plus, a grey slash and a minus. Pressing the minus turns it red and puts a red delete button at the bottom right of each task and event for that date. Each delete opens Lulyssia's window: "Delete this task?", the item's name and that it can be undone from Recent Changes, then Nevermind~ / Yes, delete it! The delete itself is the same as on the Tasks and Events pages.

Delete mode ends with the minus, on another date, on leaving Home, or once the date is empty. Clicking an item still opens its details.

"Don't ask again today"

The window gets a tick box. Ticked when you confirm, later deletes from Home's calendar go straight through (with the delete sound and message) on this device until midnight Thai time; the next day it asks again. Ticking and then pressing Nevermind~ changes nothing. Other confirm windows don't get the box.
